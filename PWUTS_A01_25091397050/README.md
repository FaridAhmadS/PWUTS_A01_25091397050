## Deskripsi
ClassPlan merupakan website untuk membantu PJ mata kuliah mengelola informasi jadwal kuliah dan tugas pada kelas 2025B.

## Teknologi
- HTML
- CSS
- JavaScript
- jQuery

Website menggunakan CSS sendiri dan tidak menggunakan Bootstrap.

## Struktur folder
- `index.html`: halaman utama dan layout website
- `css/style.css`: tampilan website dan pengaturan responsif
- `js/script.js`: data, navigasi, validasi form, dan interaksi
- `pages/dashboard.html`: ringkasan mata kuliah
- `pages/jadwal.html`: daftar jadwal kuliah
- `pages/form-jadwal.html`: form pengubahan jadwal
- `pages/tugas.html`: pengelolaan tugas

## Cara menjalankan
1. Ekstrak file project.
2. Buka folder project di Visual Studio Code.
3. Jalankan `index.html` menggunakan Live Server.
4. Dashboard akan terbuka langsung saat `index.html` dijalankan.

## Fitur
- Ringkasan mata kuliah yang dikelola.
- Melihat dan mengubah informasi jadwal kuliah.
- Menambah, mengubah, dan menghapus tugas.
- Validasi isian pada form.
- Navigasi halaman menggunakan jQuery.
- Tampilan responsif untuk ukuran layar berbeda.
